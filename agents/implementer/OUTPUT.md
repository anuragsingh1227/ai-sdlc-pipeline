# Implementer outputs

| Output | Where |
| --- | --- |
| Product code and unit tests | Product repository, on a feature branch |
| Change summary | `runs/<feature-id>/05-implement/change-summary.md` |

The change summary headings are `## Product repo changes`, `## Tests`, and `## Scope check`.

`## Product repo changes` lists paths and what each file does. `## Tests` maps each AC story to a test name and the command to run it. `## Scope check` lists AC items you implemented and nearby ideas you left out.

Do not write the code-critic review or the MR description.
